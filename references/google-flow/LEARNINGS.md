# Aprendizados verificados — Google Flow

Registro incremental de descobertas obtidas em trabalhos reais. Ele complementa a base canônica; não substitui a documentação oficial.

## Critérios de inclusão

- Registrar somente fatos, padrões operacionais ou decisões úteis que tenham evidência verificável.
- Identificar se o item é `FATO OFICIAL ATUAL`, `MELHOR PRÁTICA DERIVADA`, `RECURSO HISTÓRICO/ANTIGO` ou `INCERTO/SUJEITO A ROLLOUT`.
- Para informações dinâmicas, indicar a data de verificação e a fonte oficial.
- Nunca registrar segredos, tokens, dados pessoais, conteúdo privado de contas ou suposições apresentadas como fatos.
- Se uma descoberta substituir conhecimento existente, atualizar a base e o JSONL na mesma alteração, preservando fontes e `last_verified`.

## Modelo de registro

```md
### AAAA-MM-DD — título curto

- Tipo: FATO OFICIAL ATUAL | MELHOR PRÁTICA DERIVADA | RECURSO HISTÓRICO/ANTIGO | INCERTO/SUJEITO A ROLLOUT
- Escopo: modelo, recurso, plataforma e região/plano quando relevante
- Aprendizado: descrição objetiva
- Evidência: URL oficial, teste reproduzível ou artefato local não sensível
- Verificado em: AAAA-MM-DD
- Impacto: como aplicar em próximos trabalhos
```
