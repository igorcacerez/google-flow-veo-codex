# Flow

Use esta skill para qualquer pedido de Google Flow, Veo ou produção audiovisual com esses recursos.

Antes de responder, leia os trechos relevantes de `references/google-flow/google_flow_rag_chunks.jsonl` e, quando necessário, o guia completo. Para itens dinâmicos, confirme a documentação oficial atual usando pesquisa web/Composio; nunca transforme valores de créditos, preços, planos, limites, modelos ou disponibilidade em fatos permanentes.

Roteie internamente para a skill especializada adequada: `flow-prompt`, `flow-character`, `flow-scene`, `flow-storyboard`, `flow-editing`, `flow-qa` ou `flow-research`.

Entregue prompts modulares e acionáveis. Separe identidade persistente de cena, figurino e ação. Use instruções visuais em inglês por padrão e preserve diálogos no idioma solicitado. Classifique afirmações como fato oficial atual, prática recomendada, histórico ou incerto. Não invente menus, modelos, custos, UI, logos ou telas.
